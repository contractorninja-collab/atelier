# Atelier brand assets

Mark: **Aperture** — a single-storey `a` reduced to a ring and a stem.
Colourway: **petrol & saffron** (4c).

| File | Use |
| --- | --- |
| `atelier-mark.svg` | primary mark, light backgrounds |
| `atelier-mark-reversed.svg` | on ink / petrol backgrounds |
| `atelier-mark-mono-ink.svg` | one-colour ink (print, fax, embroidery) |
| `atelier-mark-mono-white.svg` | one-colour knockout |
| `atelier-logo-horizontal.svg` | primary lockup |
| `atelier-logo-stacked.svg` | square-ish placements |
| `atelier-icon-app.svg` | 256px app icon / OG avatar |
| `atelier-favicon-32.svg` | favicon (stem shortened for 16px legibility) |
| `atelier-tokens.css` | drop-in replacement for the token ramp in `src/app/globals.css` |

Colours: petrol `#0F6B73`, petrol tint `#7FD0CB`, saffron `#E2A63A`, ink `#0A1618`, paper `#F5F8F8`.

Wordmark type: Plus Jakarta Sans 800, tracking -0.045em. The two lockup SVGs use live text —
outline the text (or install the webfont) before sending them outside the app.

Rules: minimum mark size 16px; clear space equal to the ring radius on all sides; never
recolour the stem to anything but saffron, white or ink; saffron is for attention states only,
never a button fill.
